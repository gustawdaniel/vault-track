# API Reference

The VaultTracker backend exposes a REST API documented via **Swagger/OpenAPI**.

## Live Documentation

When running the backend, interactive API docs are available at:

```
http://localhost:4500/documentation
```

Production: `https://api.vaulttrack.org/documentation`

## Endpoints

### Health Check

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/health` | Returns server status and timestamp |
| `GET` | `/` | Returns app name and version |

### Currency (`/api/currency`)

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/api/currency/rates` | Get current exchange rates |

### Users (`/api/users`)

| Method | Path | Description |
|--------|------|-------------|
| `POST` | `/api/users/register` | Create a new user account |
| `POST` | `/api/users/login` | Authenticate and get a session |

### Receipts (`/api/receipts`)

| Method | Path | Description |
|--------|------|-------------|
| `POST` | `/api/receipts/scan` | Upload a receipt image for AI-powered OCR extraction |

### Sync (`/api/sync`)

| Method | Path | Description |
|--------|------|-------------|
| `POST` | `/api/sync/push` | Push local changes to the server |
| `GET` | `/api/sync/pull` | Pull remote changes to local |

### Admin (`/api/admin`)

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/api/admin/users` | List all registered users |

## Authentication

Most endpoints require authentication via session tokens. The token is set after a successful login via `/api/users/login`.

The `x-sync-group-id` header is used to identify which sync group a user belongs to.

## Request Validation

All requests are validated using **Zod** schemas. Invalid requests return a `400` status with detailed validation errors.
