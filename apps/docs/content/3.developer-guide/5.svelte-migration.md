# Svelte Migration: Feature Gaps

The main application is `apps/svelte` (Svelte 5 + Vite, served at www.vaulttrack.org). `apps/legacy-vue` is the previous Nuxt version. It is no longer developed, but it is still the source of the Tauri desktop/Android builds and the reference for porting features.

This page lists what the Vue version can do that the Svelte version cannot do yet. It comes from a comparison of the code as of 2026-10-25. Update it as features get ported.

## Missing in Svelte

Ordered by priority.

### 1. Bank statement CSV import

Vue has a full import wizard. You upload a bank CSV, map its columns (date, amount or separate in/out, payee, memo), pick the date format, preview the rows and confirm before the transactions are created.

- Vue: `components/account/UploadTransactionsToAccount.vue`, `components/account/UploadTransactionAcceptance.vue`, `components/account/tableHeadersToTransactionKeys.ts`, `components/dialog/ConfirmBulkTransactionsCreate.vue`, `utils/transactionImport.ts`, `utils/parseTextAsCsv.ts`
- Svelte: no CSV import. Transactions arrive only through bank connectors (backend) or a full JSON backup.

### 2. QIF import and export

QIF is the CashDroid format. Older backups (`backup-*.qif`) can only be loaded by the Vue app.

- Vue: `components/backup/ImportQif.vue`, `components/backup/ExportQif.vue`, `components/backup/parseFileContent.ts`, `components/backup/getExportContent.ts`
- Svelte: JSON backup only (`exportBackupJson`, `importBackupIntoLocalDB`).

### 3. Transaction CSV export

- Vue: `utils/exportTransactionsCsv.ts`
- Svelte: missing.

### 4. Category and project management

Vue manages categories and projects as entities. You can list them, rename them, set colours, delete them and open a category dashboard.

- Vue: `components/category/CategoryDashboard.vue`, `components/category/SingleCategoryEdit.vue`, `components/project/ProjectList.vue`, `components/project/SingleProjectEdit.vue`, `pages/category/[id].vue`, `pages/project/[id].vue`
- Svelte: `appState.categories` and `appState.projects` are replayed from events, but the UI never emits `CATEGORY_*` or `PROJECT_*` events. A category is just the text typed on a transaction, so it cannot be renamed, coloured or removed.

### 5. Deleting and reordering accounts

- Vue: `components/account/SingleAccountEdit.vue` (position order field), account delete.
- Svelte: an account can only be hidden. `ACCOUNT_DELETED` and `ACCOUNT_REORDERED` are never emitted.

### 6. Transaction cleared status

- Vue: `components/transactions/input/ClearedStatusPicker.vue`, `store/clearedStatus.ts`
- Svelte: the edit form keeps the existing `clearedStatus` but offers no way to set it.

## Smaller gaps

| Feature | Vue | Svelte |
|---------|-----|--------|
| Daily spending per account | `pages/account/[id]/daily.vue` | missing |
| Exchange rates viewer | `components/settings/ExchangeRatesViewer.vue` | rates are fetched but not shown |
| Onboarding for a new user | `pages/setup.vue` | missing |
| Landing / "why" pages | `components/landing/LandingPage.vue`, `pages/why.vue` | only `privacy.html`, `terms.html` |
| Clear all local data | `components/backup/ClearAllData.vue` | `clearAllLocalData` exists, used only by "reload from server" |

## To verify: long transaction lists

Vue renders only the rows on screen (`components/transactions/VirtualTransactionRow.vue`) and prepares the list in a Web Worker (`workers/transaction.worker.ts`). Svelte renders every row and relies on CSS `content-visibility`. Check that this stays smooth with real data (tens of thousands of transactions) before deciding whether virtualisation is needed.

## Not worth porting

- **Budgets** (`pages/budgets.vue`) and **schedules** (`pages/schedules.vue`): placeholders in Vue, with no working functionality.
- **Debug tools**: `pages/debug.vue`, `components/debug/FpsCounter.vue`, `pages/version.vue`.

## Already better in Svelte

These are not in the Vue version, or are weaker there:

- split transactions (`src/lib/split.ts`)
- AI receipt scanning (`src/lib/receipt.ts`)
- reconciliation with balance asserts and auto-fix of failing asserts
- bulk categorisation
- bank connectors status and the MCP cockpit
- monthly, grouped-category and cash-flow analytics (`src/lib/engine.ts`)
- live sync between browsers and devices (long polling, `src/lib/sync.ts`)
