# Setting Up Development Environment

## Prerequisites

- **Node.js** v24+
- **pnpm** v10+ (installed via Corepack)

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/gustawdaniel/vault-track.git
   cd vault-track
   ```

2. Enable Corepack (for pnpm):
   ```bash
   corepack enable
   ```

3. Install dependencies:
   ```bash
   pnpm install
   ```

4. Start all apps in development:
   ```bash
   pnpm dev
   ```

## Running Individual Apps

```bash
# Frontend only
pnpm --filter ui dev

# Backend only
pnpm --filter backend dev

# Documentation
pnpm --filter vault-track-docs dev
```

## Project Structure

| Directory | Description |
|-----------|-------------|
| `apps/ui` | Main Nuxt 4 SPA — the user-facing application |
| `apps/backend` | Fastify REST API with Swagger docs at `/documentation` |
| `apps/admin` | Admin dashboard (Nuxt 4 SSR) |
| `apps/docs` | This documentation site (Docus) |

## Building for Production

```bash
# Build everything
pnpm build

# Build specific app
pnpm --filter vault-track-ui build
```

## Environment Variables

Copy `.env.example` to `.env` in the relevant app directory:

- **`apps/ui`**: Set `BACKEND_URL` to point to your backend
- **`apps/backend`**: Set `TURSO_DATABASE_URL`, `REDIS_URL`, and `ADMIN_TOKEN_SECRET`

See the [Architecture](/developer-guide/architecture) page for the full list of environment variables.

## Local Database Debugging (SQLite)

If you need to inspect the local database running on the backend:

```bash
# Open the database
sqlite3 apps/ui/local.db

# List tables to verify
.tables
# Output should be: events

# See data
SELECT * FROM events;

# (or nicer formatting)
.mode column
.headers on
SELECT * FROM events LIMIT 5;

# Exit
.quit
```
