# Import & Export

VaultTracker supports multiple file formats for importing and exporting your financial data.

## Supported Formats

| Format | Import | Export | Use Case |
|--------|--------|--------|----------|
| **QIF** | ✅ | ✅ | Standard personal finance format (Quicken compatible) |
| **JSON** | ✅ | ✅ | Full backup with all data (recommended) |
| **CSV** | ✅ | ❌ | Bank statement imports |

## Full Data Backup

### Import

Use the **Backup** page to import QIF or JSON files. JSON format is recommended as it preserves all data including projects — QIF format has no native project support.

### Export

Export your complete data to QIF or JSON from the Backup page. The export includes:
- All accounts with settings
- All transactions
- All categories with colors
- All projects

## Bank Statement Import (CSV/JSON)

For importing transactions from your bank into an existing account:

1. **Upload** — select a CSV or JSON file exported from your bank
2. **Map Columns** — for CSV, the app tries to auto-detect columns (date, amount, payee, etc.). You can adjust the mapping manually
3. **Duplicate Detection** — transactions are compared against existing data by date and amount. Duplicates are highlighted side-by-side
4. **Resolve Conflicts** — for each duplicate, choose to keep the imported version or your existing data
5. **Save** — confirmed transactions are added to the selected account

::callout{type="info"}
Bank statement import does not support transfers between accounts. Use it for importing external bank data only.
::

## Data Management

The Backup page also shows **Stats** — a summary of how much data is stored locally (accounts, transactions, categories, projects). You can **Clear All Data** to reset the app completely.
