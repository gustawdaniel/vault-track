# Reference Notes

## QIF Specification

VaultTracker uses an extended QIF format with multi-currency support. The original spec: [QIF Specification](http://moneymvps.org/articles/qifspecification.aspx)

The `qif2json` and `qif-ts` packages are maintained as part of this monorepo with custom extensions for currency handling.

## API Documentation

When running the backend locally, Swagger/OpenAPI docs are available at:

```
http://localhost:4500/documentation
```
