# Backup & Sync

VaultTracker stores all your data locally in the browser's IndexedDB. This means your data is always fast and private — but you need to manage backups yourself.

## Local Backup

The **Backup** page provides tools to safeguard your data:

### Export

Export a full snapshot of your data at any time. Supported formats:

- **JSON** (recommended) — preserves all data including projects, colors, and settings
- **QIF** — standard financial format, compatible with Quicken and other apps

### Import

Restore from a previous backup by uploading a JSON or QIF file. The import process:

1. Parses the file and validates the data
2. Loads accounts, transactions, categories, and projects into local storage
3. Replaces any existing data

### Clear All Data

Use the **Clear All Data** button to completely reset the application. This removes all accounts, transactions, categories, and projects from local storage.

::callout{type="warning"}
Clear All Data is irreversible. Always export a backup first.
::

## Stats

The Backup page shows a summary of your stored data — total counts of accounts, transactions, categories, and projects — so you can verify your backup is complete.

## Device Sync

::callout{type="info"}
Device Sync is an optional server-side feature that requires the backend to be running.
::

VaultTracker supports **encrypted device-to-device synchronization** via the backend. This allows you to use the same data across multiple devices (e.g., laptop and phone).

### How It Works

1. Your local changes are captured as events
2. Events are pushed to the server when online
3. Other devices pull and apply these events
4. The server stores sync data in **Redis** (production) or **filesystem** (development)

### Setting Up Sync

1. Deploy the backend with a `REDIS_URL` configured
2. Create a user account via the admin panel
3. Log in on each device you want to sync
4. Your data will automatically sync in the background
