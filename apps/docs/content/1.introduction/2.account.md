# Accounts

Accounts are the top-level containers for your financial data. Each account represents a real-world financial instrument — a bank account, cash wallet, credit card, or cryptocurrency wallet.

## Account Types

| Type | Description | Example |
|------|-------------|---------|
| `Cash` | Physical currency | "Wallet PLN" |
| `Bank` | Bank account | "ING Savings" |
| `CCard` | Credit card | "Visa Gold" |

## Multi-Currency Support

Every account has an assigned **currency**. VaultTracker supports major world currencies and **Bitcoin (BTC)** with 8-decimal precision. The exchange rates are fetched daily from the backend, allowing you to view your total portfolio in any base currency.

## Account Properties

```ts
export interface Account {
    id: string;          // unique identifier
    name: string;        // display name (e.g. "ING Checking")
    type: AccountType;   // Cash, Bank, or CCard
    currency: Currency;  // e.g. USD, EUR, PLN, BTC
    description?: string; // e.g. account number
    order?: number;      // sort order in the UI
    hidden?: boolean;    // archive without deleting
}
```

## Features

- **Balance Calculation** — account balance is computed in real-time from all assigned transactions
- **Reordering** — drag accounts to set your preferred display order
- **Archiving** — hide old accounts without losing data (set `hidden: true`)
- **Desktop Split View** — on screens wider than 768px, clicking an account opens its transactions side-by-side

## Creating an Account

1. Click **"+ Account"** or navigate to `/account/new`
2. Enter the account name, select type, and choose currency
3. The account appears immediately in the sidebar

All account data is stored locally in IndexedDB — no server required.
