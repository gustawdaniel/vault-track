# Transactions

Transactions are the core data unit in VaultTracker — every income, expense, and transfer is recorded as a transaction.

## Transaction Properties

| Field | Type | Description |
|-------|------|-------------|
| `account` | string | Account name (display field) |
| `accountId` | string | Source of truth — links to account |
| `amount` | number | Positive = income, negative = expense |
| `date` | string | `YYYY-MM-DD` format |
| `payee` | string | Who you paid / received from |
| `memo` | string | Additional notes |
| `category` | string | Category and project (see below) |
| `clearedStatus` | enum | Reconciliation status |

## Cleared Status

| Symbol | Status | Description |
|--------|--------|-------------|
| *(blank)* | Unreconciled | New, unverified transaction |
| `*` | Cleared | Confirmed with source |
| `X` | Reconciled | Matched against bank statement |
| `?` | Void | Cancelled transaction |

## Receipt Scanning

VaultTracker uses **AI-powered OCR** to extract transactions from receipt photos:

![Receipt Scanning](/images/receipt.png)

1. Click the **"Scan Receipt"** button in the transaction form
2. Select or drag & drop a receipt image
3. The AI automatically extracts:
   - **Shop Name** (Payee)
   - **Date**
   - **Total Amount**
   - **Line Items** (as split transactions)

Receipt scanning requires the backend to be running (uses LLM for processing).

## Split Transactions

Split a single payment across multiple categories — useful when one purchase covers different budget areas (e.g., groceries + household supplies at the same store).

### How it works

- **Total Amount**: The full amount paid to the payee
- **Splits**: Individual line items that sum up to the Total Amount
- **Remaining**: Shows the difference between Total and Splits (must be `0.00` to save)

When scanning a receipt, VaultTracker automatically creates splits for each product line with suggested categories.

## Transfers

Transfers between your own accounts are represented as a **pair of transactions** — one debit and one credit. The `category` field uses the format `[Target Account Name]` (in square brackets) to denote a transfer destination.
