### Cleared Status

Cleared status.
Values are blank (unreconciled/not cleared),
"*" or "c" (cleared) and "X" or "R" (reconciled).

| Sign | Meaning      | Docs                     |
|------|--------------|--------------------------|
|      | Unreconciled | unreconciled/not cleared | 
| *    | Cleared      | "*" or "c" (cleared)     |     
| X    | Reconciled   | "X" or "R" (reconciled)  |
| ?    | Void         | not mentioned            |


```ts
export type ClearedStatus = '' | '*' | 'X' | '?';
export type ClearedStatusName =
    | 'Unreconciled'
    | 'Cleared'
    | 'Reconciled'
    | 'Void';

export const clearedStatusMap = new Map<ClearedStatus, ClearedStatusName>([
    ['', 'Unreconciled'],
    ['*', 'Cleared'],
    ['X', 'Reconciled'],
    ['?', 'Void'],
]);
```

## Receipt Scanning

VaultTracker allows you to quickly add transactions by scanning receipts.

![Receipt Scanning](/images/receipt.png)

1.  Click the "Scan Receipt" button in the transaction form.
2.  Select or drag & drop a receipt image.
3.  The system will automatically extract:
    *   **Shop Name** (Payee)
    *   **Date**
    *   **Total Amount**
    *   **Line Items** (Splits)

If the receipt contains multiple items, the system will switch to **Split Transaction** mode automatically.

## Split Transactions

A Split Transaction allows you to divide a single transaction into multiple categories. This is useful when a single purchase at a store includes items from different budget categories (e.g. "Groceries" and "Household Supplies").

### How it works
*   **Total Amount**: The full amount paid to the payee.
*   **Splits**: Individual line items that sum up to the Total Amount.
*   **Remaining**: Shows the difference between the Total Amount and the sum of Splits. It must be 0.00 to save the transaction.

By scanning a receipt, VaultTracker often anticipates the splits for you, extracting each product line with its price and suggesting a category.
